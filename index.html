The Unapplauded is an AI-powered personal museum that turns small everyday victories into museum-style exhibits.   • Supports PWA installation and is deployed on Vercel

ProbAI-Tool｜DLT Trend Analysis & Prediction Tool Open Source
2026.05 - Present · AI Tool

A lottery trend analysis and multi-strategy prediction tool built with Flask and scikit-learn. It scrapes real-time draw data from Sina, applies a rule engine and ML models for multi-dimensional number scoring, structure prediction, and combination generation, supporting 8 prediction modes, backtesting, and play history management.

  • Implements 8 prediction modes: basic filtering, shape constraints, number killing, dan-tuo, partition modeling, multi-strategy hedging, backtesting, and ML scoring
  • ML pipeline: Logistic Regression baseline + HistGradientBoosting main model + RandomForest structure classifier
  • 16-dimensional per-number features + 13-dimensional structure features, with per-issue model caching via joblib
  • Rolling-window backtesting compares stability and hit performance across four strategies
  • SQLite stores play history with favorites, diff comparison, and post-draw auto-settlement
  • Provides JSON API endpoints for programmatic access to trend data and predictions
